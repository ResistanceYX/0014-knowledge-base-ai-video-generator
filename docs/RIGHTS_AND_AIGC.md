# 权利、许可与 AI 标识（M3）

## 内容与代码

- 本仓库自写代码使用 MIT；输入节点和衍生内容不因该许可自动变成 MIT。
- 远程 `ResistanceYX/idea-tree` 节点按仓库公开许可记录 CC BY-SA 4.0 和 LICENSE 链接；发布者仍需履行署名与相同方式共享义务。
- 本地输入和合成 fixture 默认使用 SPDX `NOASSERTION`，表示工具不作许可断言，不表示无版权或可任意使用。
- 节点中的第三方论文、图片、音乐、声音、视频和证据链接不由节点许可自动覆盖。当前只保留节点文本和链接字符串，不抓取或复制这些材料；画面由本地程序化组件生成，没有外部素材授权被推定为已取得。
- 模板声明的字体栈包含 Noto Sans CJK SC、Source Han Sans SC、Microsoft YaHei 和系统 sans-serif；字体文件不随仓库分发，实际渲染环境的字体与许可由部署者核对。
- Remotion 4.0.545 使用其专用许可；React、其他 npm 依赖、无头浏览器和 Remotion 准备的渲染组件分别保留各自许可。本仓库不分发这些二进制。

## Edge TTS 与音频

- 真实配音路径是可选外部依赖 `edge-tts==7.3.1`，本次在其包元数据中核实为 LGPL-3.0；该 Python 包不捆绑进本仓库，MIT LICENSE 不覆盖它。
- 代码包许可与 Edge 在线服务、预设声音、生成音频的使用权利是不同问题。无 API Key 不等于确认免费、可商用、获得声音授权或服务可持续。
- 每个音频工程写入 `audio/rights.json`，记录配音模式、依赖版本、服务条款未知状态和第三方音乐／画面清单。当前示例没有第三方音乐或库存画面。
- 示例 MP3 是对合成文本实际生成的候选音频，不对应真实人物、真实项目或已获得商业发布授权的结论。发布者须另核微软服务条款、声音使用边界、平台要求和实际账单。

## 三层 AI 标识分别处理

1. **画面**：所有场景页眉显示“AI 生成 · 人工复核”，并保留实际审校状态；结尾区分无声、fixture 和 Edge 配音。
2. **文件元数据**：`media/metadata.json` 保存完整映射；MP4 标准 `title`、`comment`、`description`、`copyright` 等字段写入 AI 草稿、审校、来源与不自动发布信息。自定义 `ai_generated` 等键保存在 JSON 中，但 MP4 容器不保证保留非标准键，因此标准文本字段才是实际容器声明的一部分。
3. **平台作者声明**：`publish/ai-disclosure.json` 与 `publish/description.md` 提供 AI 系统、原节点、快照、配音模式、权利边界和纠错入口模板。

第三方模型或平台已有水印，不等于完成上述三层义务。`publish-check` 只检查本地准备状态，人工清单不会由工具自动勾选；`ready=true` 仍不代表已经上传、发布、获得授权或符合所有法域和平台要求。发布决定与公开纠错由创作者负责。
