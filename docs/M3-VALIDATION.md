## 60—90 秒真实配音合成样片

工程：`examples/synthetic-node-m3/generated`。

- 8 个场景、8 段真实中文 MP3；voice `zh-CN-XiaoxiaoNeural`，rate `+10%`。
- 8 次 Edge 调用，0 次重试；费用 `unknown/null`，没有写成免费。
- 真实音频驱动 2557 帧，视频流 85.233 秒；容器与 AAC 音频流约 85.248 秒。
- 1280×720、16:9、30fps、H.264＋AAC，48kHz 双声道封装。
- 完整 MP4 大小 5,195,566 字节；按 `.gitignore` 不提交 `media/output`，示例保留原始 MP3 与全部可复现工程数据。
- `volumedetect` 实测 `mean_volume=-22.6 dB`、`max_volume=-5.1 dB`，证明不是静音轨；这不等于语音质量验收。
- 从最终 MP4 逐一抽取 8 个场景中点画面，检查标题、字幕、来源、限定条件和 AI 标识。第一次全片的结尾残留“M2 程序化无声草稿”，已改成随配音模式显示并重渲染；第二次全片结尾抽帧复检通过。
- 脚本与来源校验通过：8 个场景、8 条合并来源记录，原节点要求的证据／推理边界、结论边界、备注、状态和可拆零件限定仍保留。
- `publish-check` 为 not-ready：整稿、逐句审校和 7 项人工清单均未完成。人工听审术语读音、可懂度、停顿与实际音画体验仍待用户完成。

## 已发现并已处理的问题

1. `edge-tts 7.2.7` 首次实测 WebSocket 403，产生 0 字节 MP3／SRT；这些文件未作为有效配音。改用全新目录安装 7.3.1 后，独立中文测试得到 4.224 秒、24kHz、单声道、25,344 字节 MP3。不能据此声称其他版本均可用。
2. 极短 fixture 场景最初使 SceneFrame 透明度关键帧倒序，Remotion 报 `inputRange must be strictly monotonically increasing`。已改为短场景安全的淡入淡出，并通过 162 帧真实音轨全片与 8 帧局部渲染。
3. 自定义 `ai_generated` 等键不保证由 MP4 容器保留；实际 `ffprobe` 中未出现这些非标准键。现以标准 `title`、`comment`、`description`、`copyright` 写入声明，同时把完整自定义映射保存在 `media/metadata.json`，没有用 JSON 文件冒充容器实测。
4. 第一次真实样片结尾阶段标识错误，已修正并保留第二次全片渲染成本。
5. M2 历史干净副本首次真实渲染曾出现一次 `Bus error`，原样重试通过，根因未完全确定；本记录不改写为“M2 从未出现渲染故障”。
6. 最终清理后的一次组合校验命令也出现退出码 135（`Bus error`）；随后把成本 Schema 与项目校验拆为直接模块调用，二者均通过。该单次环境异常根因未确定，不写成“所有命令均无瞬时故障”。
