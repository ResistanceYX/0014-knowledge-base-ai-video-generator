# M1 边界与安全约束

## 本阶段做什么

唯一闭环是：

`单个 YAML → 快照与许可记录 → idea-tree v1.9 单节点校验 → 离线保守模板 → scenes.json → source-map.json → 人工修改后重新校验`

合成示例还生成 Markdown 旁白、来源表、审校清单和成本记录。所有生成与校验都可以在本地完成。

## 本阶段不做什么

- 不调用真实模型、配音、VEO、渲染 API 或其他付费服务。
- 不实现 Remotion 渲染、MP4、字幕、音轨、WebUI、账号、批量任务或自动发布。
- 不遍历知识库，不抓取外部证据链接，不读取本地附件，不将公开 URL 视为改编授权。
- 不自动核实事实、版权、商业闭环或创作效果，不代替人工审校。

## 输入限制

- 本地输入必须是用户显式指定的普通文件，最大 1 MiB；工具不会扫描目录或读取其他本地文件。
- 远程输入只接受 `ResistanceYX/idea-tree` 的 `nodes/<四位编号>-<id>.yaml`，协议必须是 HTTPS。
- GitHub `blob` 与 `raw.githubusercontent.com` 地址可使用 `main` 或完整 40 位 commit。`main` 会先通过 `api.github.com` 固定当前 HEAD commit；随后只读取该节点与同 commit 的 `LICENSE.md`。失败时要求用户提供固定 commit，不静默使用移动分支快照。
- 拒绝 URL 凭据、查询参数、片段、非默认端口、百分号编码路径、反斜杠、其他主机、其他仓库、其他目录、保留编号 0000、短哈希和未支持标签。
- 默认不跟随重定向；单次请求超时 10 秒；按声明长度和实际流式正文双重限制大小。
- YAML 使用 core schema、唯一键和别名展开上限；自定义标签、警告和解析错误都会安全失败。节点内容不会被当成代码执行。
- 含附件、正文本地证据路径或非空 `相关节点` 的输入超出 M1 单节点验证能力，会报 `E_NODE_SCOPE`。这不是上游节点无效的结论。

## 输出与审核

- 非空输出目录必须显式允许覆盖；工具不整目录删除，也不自动上传。
- 机器只生成 `unreviewed`。审核人、审核时间和 `approved` 状态由人工填写。
- 修改节点快照后，旧哈希、来源映射和成本记录必须失效；不能用旧映射证明新文本。
- 修改旁白后必须同步检查来源表。结构校验无法证明改写后的语义仍由原文支持，这是人工审校不可省略的原因。
