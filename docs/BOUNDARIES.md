# M2 边界与安全约束

## 本阶段闭环

`单个 YAML → 快照与许可记录 → v1.9 单节点校验 → 离线保守模板 → Scene／SourceMap → 可编辑 Remotion 工程 → 字幕草稿／none 配音 → 单场景或完整无声 MP4`

所有生成、预览和渲染均在本地完成。首次安装依赖或准备 Remotion 无头浏览器可使用公开网络，但不等于访问节点证据、调用模型或调用付费服务。

## 本阶段不做什么

- 不调用真实模型、配音、VEO、素材生成或其他付费 API。
- 不实现真实音轨、音画同步、数字人、库存素材、WebUI、多语言、批量节点或自动发布。
- 不遍历知识库，不抓取外部证据链接，不读取本地附件，不将公开 URL 视为改编授权。
- 不自动核实事实、版权、商业闭环或创作效果，不代替人工审校。
- 不把短帧区间测试或低分辨率完整短拼接冒充完整时长、全高清、已审校成片。

## 输入限制

- 本地输入必须是用户显式指定的普通文件，最大 1 MiB；工具不会扫描目录或读取其他本地文件。
- 远程输入只接受 `ResistanceYX/idea-tree` 的 `nodes/<四位编号>-<id>.yaml`，协议必须是 HTTPS。
- GitHub `blob` 与 `raw.githubusercontent.com` 地址可使用 `main` 或完整 40 位 commit。`main` 会先通过 `api.github.com` 固定当前 HEAD；随后只读取该节点与同 commit 的 `LICENSE.md`。
- 拒绝 URL 凭据、查询参数、片段、非默认端口、百分号编码路径、反斜杠、其他主机、其他仓库、保留编号 0000、短哈希和未支持标签。
- 默认不跟随重定向；单次请求超时 10 秒；按声明长度和实际流式正文双重限制大小。
- YAML 使用 core schema、唯一键和别名展开上限；自定义标签、警告和解析错误都会安全失败。
- 含附件、正文本地证据路径或非空 `相关节点` 的输入超出单节点验证能力，会报 `E_NODE_SCOPE`。这不是上游节点无效的结论。

## 可编辑工程与渲染

- 节点内容只作为 JSON 数据传给固定 React 组件，不编译或执行节点中的代码、表达式和命令。
- `video/components/` 是实际打包输入；重复物化默认保留修改，只有显式 `--force-components` 才覆盖。`video/config.json` 始终保留并经白名单校验。
- `video/data.ts` 由校验后的 JSON 自动生成，不是额外事实来源；修改主 JSON 后必须重新校验和物化。
- 渲染只选择 `IdeaTreeFull` 或已登记场景的固定组合 ID。`--frames` 有组合边界检查，报告分别记录组合总帧数和实际输出帧数。
- 媒体配置只开放 1—4 并发、CRF 18—35、固定缩放档位和 `none` 配音；其他配音模式安全失败。
- 已知输出不通过符号链接写入；临时打包目录在渲染结束后删除。渲染报告不包含 API Key 或节点以外的环境变量。
- 无头浏览器由 Remotion 准备；本仓库不提交浏览器、FFmpeg 或其他渲染二进制。

## 输出、证据与审核

- 非空输出目录必须显式允许覆盖；工具不整目录删除，也不自动上传。
- 机器只生成 `unreviewed`。审核人、审核时间和 `approved` 状态由人工填写。
- `supported` 只表示指针可解析、摘录存在；画面、字幕和渲染报告都不能把该状态升级为独立核验。
- 场景画面只展示有限条来源和限定条件摘要，并明确指向完整来源表；数据层仍保留全部条目。摘要不能作为删除限定条件的依据。
- 字幕按字符数分配时间，纯属草稿；`none.json` 明确记录无音频片段、零外部调用。
- 修改节点快照后，旧哈希、来源映射和成本记录失效；修改旁白后必须同步检查来源表，结构校验不能证明改写语义仍由原文支持。
