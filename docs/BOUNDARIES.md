# M3 边界与安全约束

## 本阶段闭环

`单个 YAML → 快照与许可记录 → v1.9 校验 → 离线保守模板 → Scene／SourceMap → 可编辑 Remotion 工程 → 显式可选配音 → 真实音频时间轴／可修改字幕 → 单场景或完整 MP4 → 本地发布前检查`

脚本、fixture 和无声画面均可离线完成。安装依赖、首次准备浏览器以及显式 `edge-tts` 合成会使用公开网络，三者必须分开理解。

## 本阶段不做什么

- 不调用 VEO、素材生成或其他真实配音服务；真实配音后端最多一种，当前为 `edge-tts`。
- 不实现数字人、库存素材、WebUI、多语言、批量节点、自定义物理仿真、词级字幕或唇形同步。
- 不遍历知识库，不抓取外部证据链接，不读取本地附件，不将公开 URL 视为改编授权。
- 不自动核实事实、版权、声音权利、商业闭环或创作效果，不代替人工审校、听审和发布决定。
- 不把短帧测试、fixture 音调或一条合成样片冒充稳定质量、真实创作验收、公开发布或 M5 完成。

## 输入限制

- 本地输入必须是用户显式指定的普通文件，最大 1 MiB；工具不会扫描目录或读取其他本地文件。
- 远程输入只接受 `ResistanceYX/idea-tree` 的 `nodes/<四位编号>-<id>.yaml`，协议必须是 HTTPS。
- GitHub `blob` 与 `raw.githubusercontent.com` 地址可使用 `main` 或完整 40 位 commit。`main` 会先固定当前 HEAD，随后只读取该节点与同 commit 的 `LICENSE.md`。
- 拒绝 URL 凭据、查询参数、片段、非默认端口、编码路径、反斜杠、其他主机、其他仓库、短哈希和未支持标签。
- 默认不跟随重定向；请求有超时与大小限制。YAML 使用 core schema、唯一键和别名展开上限，自定义标签与警告安全失败。
- 含附件、本地证据路径或非空 `相关节点` 的输入超出单节点能力，会报 `E_NODE_SCOPE`，不等于上游节点无效。

## 可编辑工程、音频与渲染

- 节点内容只作为 JSON 数据传给固定 React 组件，不编译或执行节点中的代码、表达式和命令。
- `video/components/` 是实际打包输入；重复物化默认保留修改，只有 `--force-components` 才覆盖。`video/config.json` 始终保留并经白名单校验。
- 媒体配置只开放 `none`、`fixture`、`edge-tts`，以及受限并发、CRF、缩放、停顿、超时和重试；其他模式安全失败。
- Edge 使用参数数组启动 `python3 -m edge_tts`，不通过 shell 拼接文本。真实节点必须先通过整稿与逐句人工审校闸门；只有合成 fixture 可显式绕过。
- 物化、预览、渲染与 CI 不会隐式联网配音。缺少或过期清单时安全停止，不以旧音频冒充新脚本。
- 音频按项目内相对路径处理，最终文件必须普通且非符号链接；`ffprobe` 要求有效正时长、可识别编码，单段不超过 600 秒。
- 原始 `audio/clips` 与派生 `video/public/audio` 分开；物化只清理并重建派生副本，不删除原始音频。
- 渲染只选择已登记组合。音频模式启用 AAC 音轨，`none` 不伪造静音轨；报告记录输入哈希，覆盖脚本、组件、配置和音频。
- 已知输出不通过符号链接写入；临时打包目录在渲染结束后删除。日志和报告不保存 API Key。

## 输出、证据与审核

- 非空输出目录必须显式允许覆盖；工具不自动上传、不代发。
- 机器只生成 `unreviewed`。审核人、审核时间和 `approved` 状态由人工填写。
- `supported` 只表示指针可解析、摘录存在；画面、字幕、音频和渲染报告都不能把该状态升级为独立核验。
- 场景画面只展示有限摘要并指向完整来源表；压缩样片旁白也不能删除数据层必要限定条件。
- `none` 字幕按字符数估算；音频模式按真实片段对齐。术语表只改朗读文本，字幕覆盖只改显示与时间，两者都不改原始证据。
- 音频存在、非零电平、时长吻合不等于术语读音正确或人工音画验收通过。
- AI 画面标识、MP4 标准元数据、平台声明和人工清单分别提供。`publish-check ready` 不等于已发布、已授权或完成 M4／M5。
